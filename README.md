# Alexander Ng

I'm a software engineer in the Bay Area, California, focused on large-scale distributed systems and data infrastructure, especially infrastructure for real-world ML and data-intensive applications. I spent about 2.5 years at Walmart Global Tech on three supply-chain teams: Order Management Systems (event-driven purchase order processing), Inventory Forecasting (automated store-level forecast overrides), and Inventory Placement (a third-party seller forecasting platform built from the ground up), and I'm now moving to the startup space. Before that I earned a B.S. in Electrical Engineering and Computer Science at UC Berkeley, where I was course staff for data structures and did undergraduate research on multilingual NLP and cultural context in LLMs.
